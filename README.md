# Data Engineering Internship – Celebal Technologies

This repo is basically my logbook for the Data Engineering track at Celebal Technologies. Each folder is a week's worth of assignments — concepts I explored, things I built, and screenshots proving I actually did the work (and didn't just read about it 😄).

## What's Inside

- **Week 1, Week 2, Week 3...** – Weekly hands-on tasks covering SQL, Python, and cloud fundamentals
- **Week 4** – End-to-end Azure Data Factory pipeline (Storage → ADF → Destination) with metadata validation

Each week's folder has its own README with a quick walkthrough of what was done, along with relevant screenshots.

## Tech Stack Covered So Far

Python, SQL, Azure (Storage Account, Blob Containers, Azure Data Factory, IAM)

## Why This Repo Exists

Mostly for my own tracking and review, but also so anyone (mentors, recruiters, future-me) can quickly see the progress and the kind of practical exposure this internship involves — week by week, one concept at a time.
